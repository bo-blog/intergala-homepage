测试一个用Issue发blog的方法

记录一下Hokshi的改进过程吧。
在给Hokshi加上了自动commit change到GitHub的功能后，突然觉得GH的API很好用啊。想到每次发日志都要正儿八经地打开mac，再deno run xxxxxx 啥的，好像有点麻烦，不如利用一下GitHub Issues增加一个自动发文章的功能吧，这样作为一个静态博客生成器也能随时更新了。

思路是在家里的All-in-one服务器上运行一个脚本，定时抓取GitHub repo内由本人发布的、符合特定条件的Open Issues，抓到新的Issues后将其保存为新的.md文件并触发生成器的build + deploy功能，然后把Issue关闭。

现在这篇日志就是用这个思路实现的，如果能在我的博客上看到这篇日志，说明研发成功。
